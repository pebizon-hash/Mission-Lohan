OPÉRATION ANNIVERSAIRE — LOHAN
================================

Contenu
- index.html : mini-jeu responsive, HTML/CSS/JavaScript
- GTA_6_Release.jpg : image fournie dans la conversation, copiée dans les ressources du jeu

Tester sur ordinateur
1. Décompressez le ZIP.
2. Ouvrez index.html dans un navigateur récent.
3. Jouez les trois parcours possibles (un parcours par partie).
4. Pour le publier, téléversez index.html ET le dossier assets complet sur le même hébergement.

Publier gratuitement avec GitHub Pages
1. Connectez-vous à GitHub et créez un nouveau dépôt public, par exemple operation-anniversaire-lohan.
2. Téléversez index.html et le dossier assets/GTA_6_Release.jpg en conservant exactement cette structure :
   index.html
   assets/GTA_6_Release.jpg
3. Dans Settings > Pages, choisissez la branche principale (main) et le dossier /(root), puis enregistrez.
4. Attendez que GitHub Pages indique que le site est publié. Le lien sera de la forme :
   https://VOTRE-PSEUDO.github.io/operation-anniversaire-lohan/
5. Ouvrez le lien sur un smartphone Android et testez jusqu'à l'écran final avant de l'envoyer.

Important
- Le mini-jeu n'utilise aucun compte côté joueur, ne collecte aucune donnée et ne dépend pas d'un son externe.
- Le nom GTA 6 et l'image du cadeau n'apparaissent qu'à l'écran final du jeu.
- Le fichier image intégré est celui fourni dans cette conversation. Vérifiez sur téléphone que l'image s'affiche après publication.
- Je n'ai pas publié le jeu sur Internet : il faut effectuer les étapes d'hébergement ci-dessus pour obtenir un lien public réel.
